# 🦖 DINO DASH TTY (Arcade Edition)

Аркадный раннер для терминала в ретро-стиле аркадного автомата (**Arcade Cabinet Box**). 
Сочетает два полноценных режима: **Chrome Dino** и **Geometry Dash**.

---

## 🕹 Управление

| Клавиша | Действие |
|---|---|
| **`[ПРОБЕЛ]`** / **`[W]`** / **`[↑]`** | **Старт / Прыжок** (короткий тап — низкий, зажатие — высокий) / Активация сфер (★) / Рестарт |
| **`[S]`** / **`[↓]`** | **Приседание** (Dino) / **Быстрое падение** вниз в воздухе (Fast-Fall) |
| **`[M]`** | **Смена режима** (`Chrome Dino` ↔ `Geometry Dash`) |
| **`[T]`** | Звуковые эффекты SFX (Вкл / Выкл) |
| **`[P]`** | Пауза |
| **`[R]`** | Быстрый перезапуск |
| **`[Q]`** / **`[ESC]`** | Выход |

> Поддерживается как английская (`W`/`S`/`M`/`P`/`R`/`Q`), так и русская (`Ц`/`Ы`/`Ь`/`З`/`К`/`Й`) раскладка клавиатуры.

---

## 🚀 Запуск и сборка

### Быстрый запуск
```bash
./run.sh
```

### Ручная сборка
```bash
clang++ -O3 -std=c++17 -Wall -Wextra -framework ApplicationServices dino.cpp -o dino
./dino
```
