# 🦖 DINO DASH TTY (Arcade Edition)

Аркадный раннер для терминала в ретро-стиле аркадного автомата (**Arcade Cabinet Box**). 
Сочетает два полноценных режима: **Chrome Dino** и **Geometry Dash**.

---

## 🆕 Новые возможности и улучшения

1. **Чёткая аркадная рамка (`Box Frame`)**:
   - Вся игра теперь заключена в аккуратную декоративную рамку (`╔═══╗ ... ╚═══╝`), которая занимает всё окно терминала.
   - Никаких пустых областей — верхний HUD, игровая зона неба, видимая текстурированная земля (`🦴`, `💎`, `░▒▓`), разделители и нижняя панель подсказок идеально скомпонованы.
2. **Старт только по вашему действию**:
   - Игра больше не стартует внезапно! При запуске и после каждой смерти игра переходит в режим ожидания (`STATE_READY`).
   - Персонаж стоит наготове, препятствия неподвижны. Вы можете спокойно прочитать подсказку и нажать **`[ПРОБЕЛ]`** или **`[W]`**, чтобы начать бежать.
3. **Система подсказок (Tips & Tricks)**:
   - Внизу экрана в специальной рамке подсказок отображаются полезные советы по геймплею.
   - Подсказка меняется при каждом возрождении.
4. **Защита от скролла и искажений**:
   - Отключён автоперенос (`DECAWM`), убран перенос строки с нижнего края, буфер перерисовывается в реальном времени на 60 FPS без мерцания.

---

## 🕹 Управление

| Клавиша | Действие |
|---|---|
| **`[ПРОБЕЛ]`** / **`[W]`** / **`[↑]`** | **Старт / Прыжок** / Активация парящей сферы (Geometry Dash) / Рестарт |
| **`[S]`** / **`[↓]`** | **Приседание** (Dino) / **Быстрое падение** вниз в воздухе (Fast-Fall) |
| **`[M]`** | **Смена режима** (`Chrome Dino` ↔ `Geometry Dash`) |
| **`[T]`** | Звуковые эффекты SFX (Вкл / Выкл) |
| **`[P]`** | Пауза |
| **`[R]`** | Быстрый перезапуск |
| **`[Q]`** / **`[ESC]`** | Выход |
